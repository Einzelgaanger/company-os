# Legitimate Interest Assessment (LIA) — Template

**Lawful basis:** GDPR Art. 6(1)(f) legitimate interest  
**Important:** Employee **consent is not** a valid primary basis for workplace monitoring (EDPB Guidelines 05/2020). Do not offer consent as the org’s lawful basis in Loop onboarding.

| Question | Answer |
